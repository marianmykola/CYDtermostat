# CYD Thermostat

WiFi-управляемый термостат на базе ESP32-2432S028 (Cheap Yellow Display) с сенсорным экраном 2.4 дюйма.

## Особенности

- **Дисплей**: 2.4" TFT ST7789 (240x320) с сенсорным управлением XPT2046
- **Температурный датчик**: DS18B20 (цифровой, высокая точность)
- **Управление**: Реле для управления нагревателем
- **WiFi**: Веб-интерфейс для удаленного управления
- **Память**: Сохранение настроек во flash памяти
- **Режимы**: Автоматический и ручной режим работы

## Аппаратные компоненты

### Основная плата
- ESP32-2432S028 (CYD)
- Встроенный дисплей ST7789
- Сенсорный экран XPT2046

### Подключения
```
DS18B20 Датчик:
- VCC → 3.3V
- GND → GND  
- DATA → GPIO16

Реле:
- VCC → 3.3V
- GND → GND
- IN → GPIO4

Светодиод (статус):
- VCC → 3.3V (через резистор 220Ом)
- GND → GPIO2
```

## Настройка PlatformIO

### Требования
- PlatformIO IDE или VS Code с расширением PlatformIO
- ESP32 платформа

### Библиотеки
- TFT_eSPI (настроенная для CYD)
- ArduinoJson

- DallasTemperature
- WebServer (встроенная)

### Конфигурация TFT_eSPI
Файл `lib/User_Setup.h` уже настроен для CYD:
- Драйвер: ST7789
- Разрешение: 240x320
- SPI пины: MOSI(13), SCLK(14), CS(15), DC(2)

- Подсветка: GPIO21

## Компиляция и прошивка

1. Откройте проект в PlatformIO
2. Выберите плату: ESP32 Dev Module
3. Подключите ESP32 через USB
4. Нажмите Upload (→) для прошивки

## Использование

### Управление через сенсорный экран
- **Temp + / -**: Установка целевой температуры
- **Mode**: Переключение между автоматическим и ручным режимом
- **Heat ON/OFF**: Ручное управление нагревом (в ручном режиме)

### Веб-интерфейс
1. Подключитесь к WiFi сети термостата
2. Откройте браузер по IP адресу (показан в Serial Monitor)
3. Управляйте температурой и настройками

### WiFi настройка
- Первоначальная настройка через веб-интерфейс
- Сохранение учетных данных во flash памяти
- Автоматическое переподключение

## Алгоритм работы

### Автоматический режим
```
if (текущая_температура < (целевая_температура - гистерезис)) {
    включить_нагрев();
} else if (текущая_температура > целевая_температура) {
    выключить_нагрев();
}
```

### Ручной режим
- Нагрев управляется вручную через интерфейс
- Игнорирует показания датчика температуры

## Технические характеристики

- **Напряжение питания**: 5V (через USB)
- **Потребление**: ~100мА (без реле), ~200мА (с реле)
- **Диапазон температур**: -55°C до +125°C (DS18B20)
- **Точность измерения**: ±0.5°C
- **WiFi**: 802.11 b/g/n
- **Частота обновления**: 2 секунды (температура), 500мс (экран)

## Безопасность

- Защита от перегрева (максимальная температура 35°C)
- Гистерезис для предотвращения частого включения/выключения
- Индикация состояния реле светодиодом

## Настройки по умолчанию

- Целевая температура: 22.0°C
- Гистерезис: 0.5°C
- Режим: Автоматический
- WiFi: Не настроен

## Troubleshooting

### Проблемы с дисплеем
- Проверьте подключения SPI пинов
- Убедитесь что User_Setup.h соответствует вашей плате

### Проблемы с WiFi
- Проверьте учетные данные в веб-интерфейсе
- Убедитесь что сеть доступна

### Проблемы с датчиком температуры
- Проверьте подключение DS18B20
- Убедитесь что используется резистор 4.7k между VCC и DATA
